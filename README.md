# BudgetOS — Personal Budgeting Control Panel

A premium-feel, dark-mode, single-page budgeting web app built with **vanilla HTML/CSS/JS**.

## Files
- `index.html`
- `style.css`
- `script.js`

## Local usage
1. Download or clone this repository.
2. Open `index.html` directly in a modern browser.
3. Start adding income, expenses, debts, goals, and assets.
4. Data is automatically saved in `localStorage`.

## Setup notes
- No build step.
- No backend.
- No frameworks.
- No API keys.
- Works as a static site.

## Deploy to GitHub Pages
1. Push this project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main` (or your default) and `/ (root)`
4. Save and wait for the Pages URL.

## Deploy to Netlify
1. Sign in to Netlify.
2. Click **Add new site → Import an existing project**.
3. Select your repository.
4. Use these settings:
   - Build command: *(leave empty)*
   - Publish directory: `/`
5. Deploy site.

You can also drag-and-drop the project folder into Netlify Drop for instant hosting.
